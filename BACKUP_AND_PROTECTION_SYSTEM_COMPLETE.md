## 💾 How to Use Git

### Most Important Commands
```bash

git status

# Save your work
git commit -m "description"

# Undo if broken
git reset --hard HEAD

# See history
git log --oneline
```

```bash

# Merge feature
git merge feature/name

# Create savepoint

```

## 🆘 Emergency Restoration

### Scenario: "Everything broke, I need to restore!"
```bash
# Restore to last working state
git reset --hard HEAD

# Or restore to specific checkpoint
git reset --hard 5a90c4a
```

### Scenario: "I want to see what I changed"
```bash
git status          # See modified files
git diff            # See exact changes
git log --oneline   # See all commits
```

### Scenario: "I want to save multiple versions"
```bash
git commit -m "version 1"
git tag -a "v1.0" -m "First version"

# Make more changes
git commit -m "version 2"  
git tag -a "v1.1" -m "Second version"

# Later, restore to v1.0
git checkout v1.0
```

## ✨ Why This Setup is Valuable

### Before (No Git)
