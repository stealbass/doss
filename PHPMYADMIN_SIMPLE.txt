🎯 SOLUTION RECOMMANDÉE (10 MINUTES)
═══════════════════════════════════════════════════════════════════

┌───────────────────────────────────────────────────────────────┐
│ ÉTAPE 1 : Sauvegarder la Base (OBLIGATOIRE)                  │
└───────────────────────────────────────────────────────────────┘

1. Ouvrez phpMyAdmin : https://dossypro.com/phpmyadmin
2. Sélectionnez votre base de données (ex: dossypro_db)
3. Cliquez sur l'onglet "Exporter"
4. Méthode : "Rapide"
5. Format : "SQL"
6. Cliquez "Exécuter"
7. Téléchargez le fichier .sql


┌───────────────────────────────────────────────────────────────┐
│ ÉTAPE 2 : Supprimer TOUTES les Tables                        │
└───────────────────────────────────────────────────────────────┘

1. Cliquez sur l'onglet "Structure"
2. Tout en bas, cochez "Tout cocher"
3. Menu déroulant "Pour la sélection:" → "Supprimer"
4. Confirmez


┌───────────────────────────────────────────────────────────────┐
│ ÉTAPE 3 : Recréer les Tables depuis le Terminal              │
└───────────────────────────────────────────────────────────────┘

Sur votre serveur, exécutez :

php artisan migrate:fresh
php artisan db:seed


┌───────────────────────────────────────────────────────────────┐
│ ÉTAPE 4 : Vérifier                                            │
└───────────────────────────────────────────────────────────────┘

php artisan migrate:status

Puis rafraîchissez votre page web !


═══════════════════════════════════════════════════════════════════

📝 ALTERNATIVE : Script SQL à Copier-Coller
═══════════════════════════════════════════════════════════════════

Si vous voulez GARDER certaines données :

┌───────────────────────────────────────────────────────────────┐
│ Dans phpMyAdmin → Onglet SQL → Copiez ce script :            │
└───────────────────────────────────────────────────────────────┘

-- Supprimer les tables en conflit
DROP TABLE IF EXISTS `mobile_subscription_plans`;
DROP TABLE IF EXISTS `mobile_subscrption_plans`;
DROP TABLE IF EXISTS `fcm_tokens`;

-- Nettoyer la table migrations
DELETE FROM `migrations` 
WHERE migration LIKE '%mobile_subscription_plans%'
   OR migration LIKE '%fcm_tokens%'
   OR migration LIKE '%add_country_to_legal_library_tables%';

-- Message de confirmation
SELECT 'Nettoyage terminé !' AS message;


Puis dans le terminal :
php artisan migrate

🚨 EN CAS DE PROBLÈME
═══════════════════════════════════════════════════════════════════

Erreur : "Table already exists"
└─ Dans phpMyAdmin → SQL :
   DROP TABLE IF EXISTS `nom_de_la_table`;

Erreur : "Column already exists"  
└─ Dans phpMyAdmin → SQL :
   ALTER TABLE `nom_table` DROP COLUMN `nom_colonne`;

Restaurer la sauvegarde
└─ phpMyAdmin → Onglet "Importer" → Sélectionnez le .sql
