# Dossy Chat IA - Notes de version 1.0.8 (Build 15)

Date: 23 mars 2026

## Nouvelles fonctionnalités
- Ajout d'une cloche de notifications dans l'écran de chat avec badge non lu.
- Ajout d'une boite de reception locale des notifications push dans l'application.
- Ajout d'une nouvelle suggestion intelligente dans le chat avec bouton d'acces direct vers la bibliotheque Pro.

## Ameliorations
- Amelioration de l'affichage des notifications push dans le chat (meilleure lisibilite dans la popup).
- Ajout d'un message explicite dans la popup pour consulter le contenu complet dans la boite email.
- Persistance locale des notifications push recentes pour retrouver les messages apres redemarrage de l'app.

## Fiabilite et statistiques
- Ajout du suivi d'ouverture de notification push depuis l'application mobile.
- Amelioration de la fiabilite du calcul du taux d'ouverture (Avg Open Rate) grace au tracking des ouvertures.
- Renforcement de l'identification des notifications avec conservation de l'identifiant technique lors du traitement des payloads.

## Correctifs
- Correction du flux de marquage lu/non lu des notifications dans la boite de reception locale.
- Correction de la recuperation des details de notification lors de l'ouverture depuis l'app.

## Notes techniques
- Version applicative: 1.0.8
- Build number: 15
- Cible: Android (AAB release)
