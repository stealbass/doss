🎯 PROBLÈME IDENTIFIÉ:
-------------------
Les fichiers (logos, avatars, etc.) sont en stockage LOCAL mais PAS sur R2.
Quand tu changes Storage setting à R2, Laravel génère l'URL R2 mais le fichier
n'existe pas → Erreur 404.

✅ SOLUTION: Migrer les fichiers locaux vers R2
------------------------------------------------

📋 ÉTAPES À SUIVRE (5 MINUTES):

1️⃣ CONNECTE-TOI AU SERVEUR
   ssh dossypro@ssh-dossypro.alwaysdata.net

2️⃣ VA DANS LE RÉPERTOIRE
   cd ~/public_html

3️⃣ PULL LES NOUVEAUX SCRIPTS
   git pull origin main

4️⃣ TEST CONNEXION R2 (optionnel mais recommandé)
   php test_r2_connection.php
   
   ✅ Résultat attendu: "✅ Connexion R2 OK"
   ❌ Si erreur: Vérifie config R2 dans Admin → Paramètres → Stockage

5️⃣ MIGRER LES FICHIERS VERS R2
   php migrate_local_to_r2.php
   
   Le script va:
   - ✅ Copier tous les fichiers vers R2
   - ✅ Conserver les fichiers locaux (backup)
   - ✅ Afficher la progression
   
   ⏱️ Durée: 30 secondes à 2 minutes selon nombre de fichiers

6️⃣ VÉRIFIER QUE ÇA FONCTIONNE
   
   Ouvre cette URL dans ton navigateur:
   https://files.dossypro.com/uploads/landing_page_image/site_logo.png
   
   ✅ Si l'image s'affiche → MIGRATION OK !
   ❌ Si erreur 404 → Voir étape 7

7️⃣ SI ERREUR 404 (bucket pas public):
   
   a) Va sur Cloudflare Dashboard → R2 → Ton bucket
   b) Settings → Public Access
   c) Clique sur "Allow Access"
   d) Copie l'URL publique donnée (ex: https://pub-xxxxx.r2.dev)
   e) Mets à jour dans PhpMyAdmin:
      
      UPDATE settings 
      SET value = 'https://pub-xxxxx.r2.dev' 
      WHERE name = 'r2_url';
   
   f) Re-teste l'URL

8️⃣ ACTIVER R2 DANS L'ADMIN
   
   a) Admin → Paramètres → Stockage
   b) Change "Storage Setting" à "Cloudflare R2"
   c) Sauvegarde
   
9️⃣ VIDER LE CACHE
   php artisan cache:clear
   php artisan config:clear

🔟 ACTUALISE LE SITE
   Recharge la page d'accueil
   Le logo devrait s'afficher ! 🎉
