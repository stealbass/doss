  🔧 INSTALLATION SUR ALWAYSDATA (PRODUCTION)
═══════════════════════════════════════════════════════════════════════════

1️⃣  SSH sur le serveur
    ────────────────────────────────────────────────────────────────────
    ssh utilisateur@ssh-utilisateur.alwaysdata.net
    cd ~/www/


2️⃣  Pull le code
    ────────────────────────────────────────────────────────────────────
    git pull origin main


3️⃣  Installer les dépendances
    ────────────────────────────────────────────────────────────────────
    composer install --optimize-autoloader --no-dev

    OU si mise à jour complète:
    composer update --optimize-autoloader --no-dev


4️⃣  Tester l'installation
    ────────────────────────────────────────────────────────────────────
    php test_dependencies.php

    Résultat attendu: ✅ TOUTES LES DÉPENDANCES INSTALLÉES


5️⃣  Configurer .env
    ────────────────────────────────────────────────────────────────────
    Ajouter:
    
    OPENAI_API_KEY=sk-proj-YOUR_KEY_HERE
    PINECONE_API_KEY=YOUR_PINECONE_KEY
    PINECONE_ENVIRONMENT=us-east-1
    PINECONE_INDEX=dossy-documents


6️⃣  Vider les caches
    ────────────────────────────────────────────────────────────────────
    php artisan config:clear
    php artisan cache:clear
    php artisan route:clear


7️⃣  Migrations & Seeders (si pas déjà fait)
    ────────────────────────────────────────────────────────────────────
    php artisan migrate
    php artisan db:seed --class=MobileAppPlansSeeder


8️⃣  Tester l'API Mobile
    ────────────────────────────────────────────────────────────────────
    curl -X POST https://dossy.alwaysdata.net/api/mobile/register \
      -H "Content-Type: application/json" \
      -d '{
        "name": "Test",
        "email": "test@example.com",
        "password": "password123",
        "password_confirmation": "password123",
        "phone": "+237670000000"
      }'

    Résultat attendu: 200 + token + plan "Gratuit"

    → composer dump-autoload
    → php artisan config:clear

Erreur: "Memory limit exceeded"
    → php -d memory_limit=512M /usr/local/bin/composer install

    → composer self-update
    → composer install --ignore-platform-reqs
