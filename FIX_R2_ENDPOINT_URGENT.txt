═══════════════════════════════════════════════════════════════════
  ⚠️  NE PAS CONFONDRE
═══════════════════════════════════════════════════════════════════

Il y a 3 URLs différentes pour R2:

1. ENDPOINT (pour les APIs S3)
   → https://xxxxxxxxxxxxx.r2.cloudflarestorage.com
   → À mettre dans: r2_endpoint
   → Utilisé pour: Upload, delete, list files

2. PUBLIC URL (domain R2 par défaut)
   → https://pub-xxxxxx.r2.dev
   → À mettre dans: r2_url (si pas de custom domain)
   → Utilisé pour: Affichage public des fichiers

3. CUSTOM DOMAIN (votre domaine)
   → https://files.dossypro.com
   → À mettre dans: r2_url
   → Utilisé pour: Affichage public des fichiers


POUR DOSSY PRO:
- r2_endpoint = https://xxxxxxxxxxxxx.r2.cloudflarestorage.com
- r2_url = https://files.dossypro.com
