═══════════════════════════════════════════════════════════════════

┌───────────────────────────────────────────────────────────────┐
│ MÉTHODE 1 : Via phpMyAdmin (RECOMMANDÉ)                      │
└───────────────────────────────────────────────────────────────┘

1. Ouvrez phpMyAdmin : https://dossypro.com/phpmyadmin
2. Sélectionnez votre base de données
3. Cliquez sur l'onglet "SQL"
4. Ouvrez le fichier : SQL_MANUEL_COMPLET.sql
5. Copiez TOUT le contenu du fichier
6. Collez dans la zone de texte de phpMyAdmin
7. Cliquez sur "Exécuter"
8. Attendez que le script se termine (~30 secondes)


┌───────────────────────────────────────────────────────────────┐
│ MÉTHODE 2 : Via Terminal (Alternative)                       │
└───────────────────────────────────────────────────────────────┘

Sur votre serveur, exécutez :

mysql -u votre_utilisateur -p votre_base_de_donnees < SQL_MANUEL_COMPLET.sql

Ou si le fichier est sur GitHub :

cd /home/user/webapp
mysql -u votre_utilisateur -p votre_base_de_donnees < SQL_MANUEL_COMPLET.sql

🚨 EN CAS D'ERREUR
═══════════════════════════════════════════════════════════════════

Erreur : "Table 'fcm_tokens' already exists"
└─ La table existe déjà, c'est OK ! Le script utilise "IF NOT EXISTS"

Erreur : "Column 'country' already exists"
└─ La colonne existe déjà, c'est OK ! Le script vérifie avant d'ajouter

Erreur : "Duplicate entry"
└─ La migration est déjà enregistrée, c'est OK !

Erreur : "Foreign key constraint fails"
└─ Vérifiez que la table 'users' existe
└─ Exécutez : SHOW TABLES LIKE 'users';
